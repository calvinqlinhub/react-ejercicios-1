# React Lab - Entrega de ejercicios 1

Relación de nueve ejercicios sencillos desarrollados con React. La portada enlaza cada práctica y cada ejercicio mantiene su lógica en un archivo JavaScript independiente.

## Ejercicios

1. Cambiador de color de fondo.
2. Contador de clics.
3. Lista dinámica.
4. Filtro de búsqueda en tiempo real.
5. Calculadora sencilla.
6. Temporizador con inicio, pausa y reinicio.
7. Generador de contraseñas aleatorias.
8. Contador de palabras y caracteres.
9. Lista de tareas con LocalStorage.

## Tecnologías

- React 18.
- ReactDOM 18.
- HTM para escribir componentes sin proceso de compilación.
- HTML5 y CSS3 responsive.

Las librerías están incluidas en `vendor`, por lo que el proyecto funciona sin instalar dependencias.
